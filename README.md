# 코딩 AI 프롬프트 전문가 팀 (Sam · Jenny · Will)

코딩 AI(Antigravity, Cursor, Claude Code, GitHub Copilot 등)에게 줄 고품질 프롬프트를 만들어 주는 **3인 전문가 팀 시스템 프롬프트**입니다.

| 팀원 | 역할 | 전문 영역 |
|------|------|----------|
| **Sam** | 프롬프트 아키텍트 | 구조 설계, 컨텍스트 분석, 요구사항 명세 |
| **Jenny** | 기술 도메인 전문가 | 코드 패턴, 기술 스택, 베스트 프랙티스 |
| **Will** | 팀 리더 & 품질 관리 | 요청 접수, 최종 검토, 통합, 실행 가능성 검증 |

## 파일 구성
- [`prompts/coding-prompt-expert-team.md`](prompts/coding-prompt-expert-team.md) — 시스템 프롬프트 본문 (복사해서 사용)
- [`examples/react-todo-app.md`](examples/react-todo-app.md) — React + TypeScript Todo 앱 예시 (최종 프롬프트 전문 포함)

## 사용 방법
1. `prompts/coding-prompt-expert-team.md` 내용을 AI 채팅의 시스템 프롬프트(또는 첫 메시지)로 붙여넣습니다.
2. 만들고 싶은 것을 자유롭게 설명합니다. 예: "React로 Todo 앱 만들고 싶어요. 코딩은 잘 몰라요."
3. 팀이 부족한 정보를 짧게 질문한 뒤, Sam → Jenny → Will 순서로 분석하고 **최종 프롬프트**를 줍니다.
4. 최종 프롬프트를 그대로 코딩 AI에 붙여넣습니다.

## 워크플로우
0. **요청 접수 (Will)** — 목표·기술 스택·요구사항·기존 코드·사용 도구·사용자 숙련도 확인
1. **Sam** — 목적/범위 정의, 컨텍스트 분석, 구조 설계, 모호성 제거
2. **Jenny** — 기술 스택 명세, 코드 품질 가이드, 구체적 기술 지시, 테스트·보안·성능
3. **Will** — 완성도 검증, 실행 가능성 평가, 최적화, 도구별 조정, 최종 포맷팅

### 초보자 배려
사용자가 기술 스택이나 코딩을 잘 모른다고 하면, 팀이 적합한 스택과 비기능 요구사항(보안·테스트·에러 처리)을 알아서 정하고, 코딩 AI가 단계별로 쉽게 설명하며 진행하도록 최종 프롬프트에 지시를 추가합니다.

## 원본 대비 개선 사항
- 마크다운 코드 블록 안에 코드 블록이 중첩되어 렌더링이 깨지던 문제 해결 (그대로 복사 가능)
- "사용자 숙련도 확인" 요구를 **0단계 요청 접수**와 구체적인 처리 규칙으로 명문화
- 출력 템플릿에 **작업 순서**, **완료 기준** 섹션 추가 (에이전트형 코딩 AI가 스스로 검증 가능)
- 대상 도구(에이전트형/에디터형)별 조정 단계 추가
- 응답 끝에 **다음 단계 제안**(후속 프롬프트) 추가
- 예시의 드래그앤드롭 라이브러리를 유지보수 중인 `@dnd-kit`으로 확정
